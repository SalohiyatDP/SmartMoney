## 📦 O'rnatish

### Talablar

- Node.js 18+ 
- npm yoki yarn

### Bosqichlar

```bash
# Repository ni clone qiling
git clone https://github.com/SalohiyatDP/SmartMoney.git
cd SmartMoney

# Dependencies o'rnating
npm install

# Development rejimida ishga tushiring
npm run dev

# Production build
npm run build

# Windows .exe yaratish
npm run build:win
```

## 🚀 Ishga Tushirish

### Development Mode

```bash
npm run dev
```

Bu ikki jarayonni parallel ishga tushiradi:
- Vite dev server (port 5173)
- Electron app

### Production Build

```bash
# Web build
npm run build

# Windows executable
npm run build:win
```

Build fayllar `dist-electron` papkasida yaratiladi.
